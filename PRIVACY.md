# Privacy Policy — Xodusky MCP Connector

**Last updated:** October 14, 2026

Xodusky MCP Connector ("the app") is a personal, self-hosted Model Context Protocol (MCP) server operated by Xodus Design. It connects a single Pinterest account — the developer's own — to an AI assistant so the account owner can view and organize their own boards and pins. The app is not offered to the public and has no other users.

## Information the app accesses

With the account owner's authorization through Pinterest OAuth, the app may access:

- Basic account information (username, profile details)
- Boards and board sections
- Pins and pin details

The app only accesses the authenticated owner's own account. It does not access other Pinners' data.

## How information is used

Information is used only to carry out actions the account owner requests and approves, such as listing, creating, renaming, moving or deleting boards, sections and pins on their own account. Each change is reviewed and approved by the account owner before it runs.

## Storage and retention

- Pinterest data is not stored. The app calls the Pinterest API each time information is needed.
- The OAuth access token is stored locally on the owner's own computer, used only to authenticate API requests, and never shared.
- No data is kept on remote servers or in databases.

## Sharing

Information from Pinterest is never sold, shared with third parties, used for advertising, or used to train, fine-tune or develop any AI or machine learning model.

## Security

API credentials and access tokens are kept private on the owner's machine and excluded from version control.

## Revoking access

Access can be revoked at any time from Pinterest **Settings → Security and logins → Apps** (or the equivalent connected-apps section), which immediately stops the app from reaching the account.

## Children

The app is not intended for or used by children under 13.

This policy may be updated as the app changes. The date above shows the latest version.
